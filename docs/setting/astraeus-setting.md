# The Astraeus Setting

# **The Astraeus Setting**
*An isolated frontier reached by following the Light or the Beacon.*

- **Astraeus** is the principal setting within the wider Deus Proxima universe.
- Astraeus is not an entire galaxy.
- It is a compact and isolated cluster of star systems in a distant, unnamed galaxy.
- **The Light** and **the Beacon** are factional names for the same guiding phenomenon.
